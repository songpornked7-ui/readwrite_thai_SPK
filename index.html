เชื่อมต่อนิยายจาก Google Drive (Google Docs)

ยังไม่ได้เชื่อมต่อ URL
โค้ด Google Apps Script ฉบับสมบูรณ์ (doGet + doPost + CORS/JSONP) 

                


                

                    
 สรุปวิธีตั้งค่าและโครงสร้างโฟลเดอร์:

                    
• Deploy Web App: ตั้งค่า Execute as: Me และ Who has access: Anyone (ทุกคน)

                    
• โฟลเดอร์หลายเรื่อง: สร้างโฟลเดอร์ย่อยตามชื่อเรื่อง (เช่น "นอกเฟรม...เกินเพื่อน") และนำไฟล์ Google Docs แต่ละตอนใส่ไว้ด้านใน (สร้างไฟล์ชื่อ เรื่องย่อ เพื่อใส่คำโปรย นามปากกา และหมวดหมู่ได้)

                    
• โฟลเดอร์เรื่องเดียว: ใส่ไฟล์ Google Docs ทุกตอนลงในโฟลเดอร์หลักโดยตรง ระบบจะใช้ชื่อโฟลเดอร์หลักเป็นชื่อเรื่องให้อัตโนมัติ
